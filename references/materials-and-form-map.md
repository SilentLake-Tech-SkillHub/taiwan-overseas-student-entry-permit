# 材料整理与表单映射

此结构放在用户指定的**私密案件目录**，不是 Skill 或公开 Git 仓库。目录名、文件名不得含真实证件号；原件保留不覆盖。若用户已有结构，沿用并补足必要分层，不强制迁移。

```text
申请批次目录/
├── 00_官方依据与审查意见/       # 当前规则、馆处要求、旧案通知；限制访问
├── 01_原始材料/                 # 护照、身份证、居留、学籍、照片等原件，只读
├── 02_制作工作件/               # 脱敏核对表、转换中间件
├── 03_待上传文件/               # 按当前系统检查过的最终上传版
├── 04_申请与回执/               # 提交前核对包、申请号、收件号、状态截图
└── 05_补件与结果/               # 补件版本、审查结果、获批文件
```

私密材料清单至少记载：材料类别、原件来源、签发/开立日期、有效期、页数、当前系统目标栏位、拟上传文件路径、格式与大小、核对状态、用户确认、上传读回；不在公开记录中写真实值。系统或馆处要求可能变化，**以本轮可见要求为准**，不可把某次申请中的 PDF/JPG、大小上限或银行材料普遍化。

## 常见材料（按馆处和个案增减）

| 材料 | 核对重点 |
| --- | --- |
| 大陆旅行证件资料页、居民身份证正反面 | 姓名、护照号、出生日期、有效期一致；入境时的剩余效期符合当前规则 |
| 当前学生签证/居留/学生准证及再入境凭证 | 签发日、到期日、准证类别、可再入境；曾持旧准证则按真实情况准备连续居留证明 |
| 学生证、学校在学证明 | 学校、课程、在学状态、签章、开立日期和当前馆处要求；电子学生证是否被接受需查当地规定 |
| 近期白底证件照 | 近期、规格、面貌真实；不得合成或用 AI 改变五官/眼镜等事实，应重新拍摄合规照片 |
| 行程、住宿、在台联络资料 | 日期与申请证别效期相符，地址和电话能由预订或官方来源核实；未订妥则明确标注待确认 |
| 其他文件 | 银行证明、旧准证、签署行程表、未成年同意书等仅在馆处或审查意见要求时准备，不虚构 |

## 表单字段组

进入表单后先列出可见的字段和上传栏位，再建立下列映射；不要照旧案无条件复制。

1. **申请路径**：初次从海外申请与否、所属驻外馆处、留学资格、单次/一年多次、申请人数、旧案是否可补正。证别是用户选择，不因旧案失败而擅自切换。
2. **申请人身份**：中文姓名、护照英文姓名、出生日期、性别、出生地、护照号码与到期日、大陆居民身份证号、旅居地身份/准证号码、是否持其他国籍护照；若“是”，按系统要求补国籍、证件号码与有效期。英文姓名逐字符与护照比对。
3. **学籍与现职**：现职、学校全称、职称/学生身份；核对当前有效学生证、在学证明和旅居地准证的签发日与到期日。课程或学籍信息只有表单要求时填写。
4. **联系方式与在台资料**：已验证邮箱、海外手机（含国家码）、海外住址、在台联络地址、固定电话或手机，以及页面允许的“无在台手机”选项。住宿信息以实际预订/酒店官方资料核实；旅行日期与行程文件一致。
5. **家庭与身份声明**：台湾配偶、父母是否同行；父母各自的存殁、姓名、生日、电话、现职、服务单位、职称和现居地址（以当前页面实际要求为准）。政治/身份/婚姻等声明仅根据用户真实回答填写，不从旧案或职业推断。
6. **照片与附件**：按页面栏位分别上传证件照、旅行证件、学生居留/签证和在学证明、身份证及馆处/审查员要求的其他文件；读回最终文件名与上传状态。可选栏位不能替代必填栏位，附件文件已选中不等于服务器保存。

生成提交前核对包时，字段逐项标注“来源—拟填值—页面读回—差异”，附件逐项标注“本地检查—选择—服务器显示”。对证件号只展示必要的末几位，用户若需要全值在其私密页面核对。任何自动翻译、OCR 或旧案复制结果都须对照原件；无法确认的值留空并请用户确认。
